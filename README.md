# 墨水屏微信小程序

配套 [ESP-S3-EINK](../ESP-S3-EINK/README.md) 固件，支持 800×480 和 1200×1600 六色面板。根据设备广播名自动选屏。

| 标识 | 主图尺寸 | 卡上字节数 | BLE 字节数 | 默认算法 |
|---|---|---:|---:|---|
| 800 | 800×480 | 384000 | 144000 | hybrid |
| 1200 | 1200×1600 | 1920000 | 720000 | atkinson |

## 使用

微信开发者工具打开工程，编译后用手机验证。微信须获蓝牙权限；相册仅显示部分照片时，在系统设置中调整微信的照片权限。

连接 `EINK-800-xxxx` 或 `EINK-1200-xxxx`，选择照片并裁剪、调参后上传。主图通过 3bit 压缩传输，设备解包为卡上每像素 1 字节的格式。没有同名 JPEG 的卡上图片不显示缩略图。

控制命令使用有应答写。支持时，图片采用无应答快传，每 16 包及最后一个数据包使用有应答写；上传成功仍以设备 FILE_END 应答为准。设备拒收或应答超时会报错，不以进度 100% 判成功。

设备页的 Wi-Fi 开关通过蓝牙控制，默认开启，设置保存在设备内，断电保留。关闭后停止热点、路由器连接和自动 OTA 联网检查，不影响蓝牙传图，可通过同一开关重新开启。界面读取真实设备设置，并等待网络服务切换完成后提示成功；需要配套新固件，旧固件查询超时后禁用开关并提示升级。

上传、删除、选图、列表刷新和轮播设置对可能冲突的命令实行互斥。刷屏时被占用的图片需等待后重试删除。缩略图读取串行，缓存按设备隔离。连接回调、重试和管理任务绑定会话，断连或退出页面会清理。

## 电脑工具

```bash
python -m pip install -r tools/requirements.txt
python tools/param-lab-server.py
python tools/param-compare.py --panel 1200 --mode algo photo.jpg
python tools/param_upload.py --panel 1200 --name EINK-1200-B21A image.bin
```

浏览器调参使用支持 Web Bluetooth 的浏览器。必须选择与设备一致的面板；对比工具产物位于 `tools/_param_out/`，不提交版本库。

## OTA

设备页连接后读取设备实际版本，自动检查公网发布版；有新版自动下载，验证大小、完整 SHA-256、ESP32-S3 项目/版本及镜像内部摘要，提供下载进度、重试和蓝牙升级。重新进入页面间隔超过 6 小时再次检查。断连会中止请求并清理临时下载，重新连接后重新检查。旧固件不支持版本读取时提示先升级配套固件。

`config/firmware.js` 已配置 `https://classx.fun:8443/eink/release/universal/manifest.json`。清单使用固件工程 `tools/ota_release.py` 生成的 release/universal 格式，以原始 ArrayBuffer 严格限制正文小于 4096 字节，固件与清单须使用相同 HTTPS 协议、主机和有效端口，不接受用户信息、片段、IP 或其他源。404 提示清单暂未发布或不可用，不视为无需更新。支持取消，缓存固件在复用和蓝牙升级前重新核验字节数及 SHA-256。微信公众平台须配置包含 `:8443` 的 request 和 downloadFile 合法域名。见 [服务器交付清单](../ESP-S3-EINK/docs/ota-server-handoff.md)。

配套 1.1.13 起可点击“蓝牙升级固件”，按实际 MTU 分包、有应答写并等待设备逐包确认。设备后台写备用 OTA 槽，支持丢失 DATA 应答的有限重传、提交前取消及断连/超时回收。下载和提交前均核验原始文件；设备再次核对完整 SHA-256、芯片、项目和更高版本后才切换启动槽。页面隐藏会中止提交前的传输。蓝牙升级与图片管理互斥，设备 Wi-Fi 可关闭，手机需要网络下载固件。

提交成功后设备重启，页面不会直接报告升级成功。目标版本按设备ID保存在本机，重新连接后须读到目标版本并通过启动自检，才提示成功；回滚会显示版本不符。1.1.12 及更旧固件需先通过现有 HTTP 或 USB 安装一次支持蓝牙 OTA 的基础固件，之后无需通过设备 Wi-Fi 升级。HTTP 入口和设备 HTTPS 拉取作为维护方式保留。见 [固件 OTA 说明](../ESP-S3-EINK/docs/ota.md)。
