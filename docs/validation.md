# 验证

```bash
python tools/run_tests.py
```

runner 按顺序执行 tools/tests 中的 JavaScript 与 Python 测试，失败时返回非零状态，不连接真实设备。

覆盖范围：面板尺寸、图片转换、3bit 上传、命令应答、上传与管理操作互斥、缩略图队列与缓存、删除确认、蓝牙初始化、会话重试、乱序连接回调、同设备重连和旧监听清理。

主机模拟通过不等同于手机真机通过。用户已反馈快传速度提升；主图拒收的具体原因尚未由失败现场日志确认。

## 真机验收

1.1.7 固件冷启动会先广播 `EINK-STARTING-<MAC4>`。小程序显示“识别中”，不猜测屏幕尺寸；探屏和存储准备好后，同一设备行更新为真实型号。扫描中遇到启动广播时，等待窗口延长为 45 秒，防止默认 15 秒扫描先于探屏结束。主机回归覆盖缓存 name 仍为 STARTING、但新 localName 已是实际型号的更新情况。需要重新编译小程序以使用此提示。

大列表回归覆盖固件容量上限 512 张、32 页及跨通知分片，检查无遗漏和重复；单页上限与固件一致为 16 条，超长分片、重复/倒退游标、容量异常和未完整结束的列表均报错并保留上次完整结果。缩略图首张完成即更新，后续按数量或时间间隔合并更新；切后台取消未完成的缩略图读取，返回后恢复。蓝牙状态事件会使旧状态查询失效，关闭蓝牙后不依赖额外断连事件也会清理会话。上述为主机模拟结果，实际手机行为仍需验收。

当前主机模拟增加了 30 轮连接/通知就绪/断开、20 轮同会话上传（含 DATA 拒收恢复）、连接准备失败与超时收尾、首次列表有限重试及刷新失败保留旧列表。它们验证回调和状态清理，不代表手机射频、真实传输速度或长时间运行已通过。连接准备最长等待 15 秒，失败后释放旧连接再允许重试；列表成功后才替换上一份完整结果，换设备或断连会清空旧设备内容。

- 两种面板分别连续上传，核对最终画面、文件长度和预览。
- 低 MTU、不同手机系统和信号条件。
- 上传中断连、关闭蓝牙、重传及切后台恢复。
- 快速切换设备与重连同设备，确认迟到回调不修改新状态。
- 上传期间操作选图、删除、刷新和轮播，不误判应答。
- 列表滚动、缩略图中断恢复、不同设备同名图片缓存。
- 刷屏占用期间删除提示忙，刷新完成后删除成功。
- 小程序完全退出后重新进入，不重复收到蓝牙通知。

固件的深睡、OTA 和硬件边界验证见 [固件验证](../../ESP-S3-EINK/docs/validation.md)。
