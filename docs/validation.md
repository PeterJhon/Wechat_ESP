# 验证

```bash
python tools/run_tests.py
```

runner 按顺序执行 tools/tests 中的 JavaScript 与 Python 测试，失败时返回非零状态，不连接真实设备。

覆盖范围：面板尺寸、图片转换、3bit 上传、命令应答、上传与管理操作互斥、缩略图队列与缓存、删除确认、蓝牙初始化、会话重试、乱序连接回调、同设备重连和旧监听清理。

主机模拟通过不等同于手机真机通过。用户已反馈快传速度提升；主图拒收的具体原因尚未由失败现场日志确认。

## 真机验收

- 两种面板分别连续上传，核对最终画面、文件长度和预览。
- 低 MTU、不同手机系统和信号条件。
- 上传中断连、关闭蓝牙、重传及切后台恢复。
- 快速切换设备与重连同设备，确认迟到回调不修改新状态。
- 上传期间操作选图、删除、刷新和轮播，不误判应答。
- 列表滚动、缩略图中断恢复、不同设备同名图片缓存。
- 刷屏占用期间删除提示忙，刷新完成后删除成功。
- 小程序完全退出后重新进入，不重复收到蓝牙通知。

固件的深睡、OTA 和硬件边界验证见 [固件验证](../../ESP-S3-EINK/docs/validation.md)。
